# CFA — Candidate Factor Analysis

CFA is a clean research repository for analyzing candidate market and news-hype factors, constructing reproducible PostgreSQL analytical datasets, and preparing a leakage-controlled dataset suitable for Partial Least Squares modeling.

## Authority boundary

- The CFA Source of Truth workbook governs project rules, plan, file status, methodology decisions, and readiness gates.
- Directly inspected raw source data and verified PostgreSQL state govern observations and schemas.
- No ASRP implementation, package, test harness, receipt, or conclusion is authoritative in CFA.
- Legacy reference files may be transferred only as explicitly identified inputs with new CFA hashes and revalidation states.

## Repository boundary

This repository contains only documentation, schemas, code, tests, small approved references, and the CFA SoT. Raw market/news data, database backups, credentials, generated outputs, logs, and temporary files remain outside Git.

## Initial status

The repository foundation is being established. Source transfer, PostgreSQL restoration, factor definitions, and PLS readiness are not yet complete.
